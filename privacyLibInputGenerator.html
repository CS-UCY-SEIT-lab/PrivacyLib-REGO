Import

Load an existing input.json (developers can edit externally), and/or import users from CSV.
Loads & hydrates the UI from that file (request, storage, controller, users, etc.).
Expected columns: user_id, field, purpose, purpose_presented, source. (Optional: source_type.)
CSV rules
  • user_id is required.
  • If field and purpose are present, a data item is added to that user.
  • purpose_presented supports true/false/1/0/yes/no (defaults to true).
  • source defaults to user if missing.
  • Import merges into existing state (it won’t wipe your current form).
